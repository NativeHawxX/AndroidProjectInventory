# Mock REST API для лабораторной работы №4

## Запуск

В терминале, находясь в папке `mock-api`, выполнить:

```bash
npm install
npm start
```

Endpoint приложения:

```text
GET http://localhost:3000/inventory
```

Для Android-эмулятора приложение использует `http://10.0.2.2:3000/`.
Для физического телефона замените адрес в `AppModule.kt` на IPv4-адрес компьютера
в локальной Wi-Fi-сети, например `http://192.168.1.10:3000/`.
